# The desktop shell (Windows & Linux)

`ndcart-desktop` is a [Tauri v2](https://tauri.app) window over the **same**
`ndcart` server the browser mode uses — the server is bundled as a sidecar
binary, the shell picks a free port, starts it on 127.0.0.1 with your data
folder, waits for it, and opens the studio. Closing the app stops the server.
There is no second renderer and no second implementation to keep in step.

## Run it in development

```bash
# 1. Build the server the shell will launch. The sidecar file must exist even
#    for `cargo check` (tauri-build validates it), so copy it in place:
cargo build -p ndcart-server --bin ndcart
target=x86_64-pc-windows-msvc          # or x86_64-unknown-linux-gnu on Linux
mkdir -p crates/ndcart-desktop/binaries
cp target/debug/ndcart.exe "crates/ndcart-desktop/binaries/ndcart-$target.exe"   # no .exe suffix on Linux

#    (the folder is git-ignored; a release build makes a release shell)

# 2. Start the shell (opens a window; the studio data lives in your app-data dir).
cargo run -p ndcart-desktop
```

At runtime the shell prefers the bundled sidecar and falls back to an
`ndcart` found on PATH.

The first `cargo run` compiles Tauri; Linux needs the webview dev packages:

```bash
sudo apt-get install -y libwebkit2gtk-4.1-dev libgtk-3-dev \
  libayatana-appindicator3-dev librsvg2-dev
```

## Data directory

Projects live under the OS app-data folder
(`%APPDATA%/com.ndworld.ndcartographer/data` on Windows,
`~/.local/share/com.ndworld.ndcartographer/data` on Linux). Set
`ND_CARTO_DESKTOP_DATA` to keep everything on a portable drive instead.

## Building installers

```bash
cargo install tauri-cli --locked --version "^2"
cargo tauri build        # NSIS + MSI (Windows), AppImage + deb (Linux)
```

The release workflow does exactly this on every `v*` tag and attaches the
installers (with SHA-256 sums) to the GitHub release. Icons are placeholder
art generated by `crates/ndcart-desktop/make_icons.py` — replace them with
real ones when art lands and re-run the script only for regenerating sizes.
